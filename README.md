# Log Academy — учебная платформа

Веб-платформа учебного центра [Log Academy](https://logacademy.az) для ведения групп, уроков, посещаемости, оценок и домашних заданий. Интерфейс на русском, азербайджанском и английском.

## Статус

Платформа в рабочей эксплуатации: используется в учебном процессе академии — педагоги ведут на ней группы и уроки, студенты получают материалы и сдают домашние задания. Развивается.

## Роли

| Роль | Возможности |
|---|---|
| **Администратор** | всё, что доступно педагогу, по всем группам; курсы, педагоги и их выходные, администраторы, кураторы, группы, их расписание и архив, студенты (завести, изменить данные, записать из одной группы в другую), аудитории; смена пароля любому пользователю; база знаний и шаблоны курсов; статистика по педагогам; посещения платформы |
| **Педагог** | свои группы: запись в группу студентов без группы, подтверждение регистраций и доступ студентов и родителей, доп. уроки для группы и персональные, уроки, материалы, посещаемость, оценки, домашние задания и их проверка с помощью ИИ, квизы, видеоконференция; методические материалы |
| **Куратор** | приводит учеников и передаёт их педагогам: календари уроков всех педагогов, новый ученик с курсом (педагог и группа — по желанию) и сразу доп. урок, все ученики в «Студентах» — как у администратора; справочник аудиторий |
| **Студент** | свои уроки (таблица и календарь), материалы, домашние задания, диалог с педагогом, успеваемость, заработанные звёзды в шапке кабинета |
| **Родитель** | успеваемость своих детей (вкладка на каждого ребёнка) — по личной ссылке или по своему логину; только просмотр |

У каждой роли — своя инструкция в разделе «Помощь» со ссылками на описанные разделы.

## Возможности

- **Группы и расписание** — группу и её расписание создаёт администратор; группа может существовать без расписания; генерация серии уроков по дням недели, времени и длительности с заданного номера урока (номера закреплены за уроками); педагог ставит доп. уроки без номера; перенос урока на «праздник» со сдвигом последующих; календарь «Месяц / Неделя / День» с реальной длительностью уроков. Выходные педагога задаёт администратор (постоянные по неделям и отдельные дни) — они залиты в календарях, урок на выходной ставит только сам педагог.
- **Аудитории** — справочник аудиторий (номер и число мест); аудитория назначается группе по дням недели или отдельному уроку, при выборе видно, какие аудитории в это время уже заняты.
- **Персональные (доп.) уроки** — урок для выбранных учеников группы: его видят только участники, он закрывает их пропуски и в нём работают материалы, ДЗ и оценки, как в обычном уроке.
- **Уроки** — материалы из общей базы знаний (файлы, ссылки, квизы); урок открывается студентам по решению педагога или сам при первой отметке присутствия; оценки и присутствие фиксируются в полночь дня урока (по Баку). Студент сдаёт работу прямо на уроке, педагог проверяет её и ставит оценку за урок.
- **Посещаемость и оценки** — пришёл / онлайн / уважительная причина / опоздание; три оценки по шкале 0–100: за урок, за домашнее задание, экзаменационная; звёзды. Пропуск засчитывается автоматически по единому правилу для всех отчётов.
- **Домашние задания** — общие и персональные задания со сроком сдачи, ответы студентов, проверка, возврат на доработку, диалог педагога со студентом.
- **Проверка с ИИ** — для ответа на ДЗ или работы на уроке платформа собирает готовый промпт (задание, ответ, правила оценки), для работы всей группы — ZIP-пакет; педагог отдаёт его любому ИИ и вставляет ответ обратно. Оценки и комментарии «Хорошо / Плохо» появляются черновиками — педагог правит и принимает их сам.
- **База знаний** — файлы, ссылки и квизы с контролем дублей; поиск по названию при наборе и фильтры (сектор, курс, урок, тип, «Моё»); материалы раскладываются сами по папкам «Урок N», «Общее» и «Для всех» по факту использования в уроках групп; просмотр выбранного материала и где он используется; просмотр docx / xlsx / pptx в браузере через PDF; HTML-материалы и квизы открываются изолированно (по временной ссылке, без доступа к платформе и входу пользователя; урок всегда начинается с первого слайда); шаблоны материалов по курсам. Так же устроено окно «Добавить из базы» в уроке.
- **Квизы** — Flash (вопрос-ответ) и Live (игра в классе в реальном времени, вход студентов по QR-коду или коду игры, режим экзамена с оценкой в журнал); помощник собирает запрос для любого ИИ по теме и материалам урока и заполняет квиз его ответом. Квиз редактируется из Базы знаний и из урока — автором или администратором.
- **Регистрация студентов** — по ссылке или QR-коду группы, либо администратор или куратор заводит студента сам — в группу или только с курсом и педагогом (педагог потом запишет его в группу); логин создаётся из имени и фамилии, пароль сначала равен логину; доступ ученика и родителя отправляется в WhatsApp из карточки ученика.
- **Связь с группой** — у каждой группы постоянная ссылка на видеоконференцию (Google Meet или другой сервис), Telegram и WhatsApp; три значка входа на странице группы и урока у педагога, администратора и студента.
- **Отчёты** — таблица студентов со средними оценками, пропусками и опозданиями; отчёт по ученику за месяц для родителей и отчёт по педагогу, оба с печатью; посещаемость по педагогам.
- **Посещения платформы** — кто сегодня заходил в систему и кто в ней сейчас (активен за последние 10 минут); отчёт за период по пользователям, ролям и группам: дни, первый вход, последняя активность, время в системе. Учитывается только время — без IP, браузера и открытых страниц; данные хранятся год.
- **Методические материалы** — раздел «Методика преподавания IT детям» для педагогов и администраторов: статьи по педагогике, управлению классом, планированию, методикам, оцениванию и работе с родителями.
- **Автоперевод (RU / AZ / EN)** — тексты интерфейса, включая подсказки, извлекаются из кода и переводятся автоматически; инструкции и методические материалы переводятся целиком с сохранением оформления. Единый глоссарий терминов академии, проверка качества каждого перевода, переводы хранятся вместе с исходниками.
- **Профиль** — фото пользователя: загрузка файла или снимок с камеры; фото показывается в списках, журнале и отчётах. Выбор пользователя (фильтры, вид страниц, язык интерфейса) хранится в его профиле и действует на любом устройстве; язык можно выбрать на странице входа.
- **Приложение на телефоне** — платформу можно поставить значком на рабочий стол (Android и iPhone); при установке спрашивается согласие на уведомления.
- **Права ролей** — у каждой роли набор прав в одном месте кода; новая роль — новая строка, меню и кнопки показываются по правам.
- **Защита данных при удалении** — нельзя удалить объект, который где-то используется; система показывает, где именно.

## Логи и бэкапы

**Логи.** Ни один лог не растёт без ограничений:

| Что | Где | Ограничение |
|---|---|---|
| Контейнеры (backend, frontend, nginx) | `docker compose logs` | до 30 МБ на сервис (3 файла по 10 МБ), `docker-compose.prod.yml` |
| Попытки входа (для fail2ban) | `logs/nginx-fail2ban/login.log` | logrotate: раз в неделю или при 20 МБ, 4 архива — `deploy/logrotate/logacademy` |
| Системный журнал | journald | `SystemMaxUse=100M` |
| auditd | `/var/log/audit` | 5 файлов по 10 МБ, режим `ROTATE` |
| Кэш сборки Docker | — | `lms deploy` (`scripts/lms.sh`) после выкатки удаляет кэш старше 3 дней |

Backend пишет в stdout через `logging` (уровень INFO), без `print`.

**Нарушения CSP.** Браузеры шлют отчёты на `/api/csp-report` (`report-uri` в заголовке CSP, `deploy/nginx/prod.conf`). Они не пишутся в лог, а складываются в таблицу `csp_reports` с дедупликацией: одна строка на вид нарушения (директива + домен источника + страница с `:id` вместо id + файл:строка), повтор только увеличивает `count` и обновляет `last_seen`. Расширения браузера отбрасываются, видов — не больше 1000. Просмотр — консольная утилита `app/csp_report_list.py` на сервере, с очисткой после разбора.

**Бэкапы.** `scripts/backup.sh` (systemd-таймер `logacademy-backup.timer`, каждый день в 03:15 по Баку, от имени `quizadm`) кладёт в `/var/backups/logacademy/<дата>_<время>/`:
- `db.dump` — база (`pg_dump -Fc`);
- `files.tar.gz` — папка файлов платформы `/var/lib/logacademy/data`, кроме кэша предпросмотров `previews/`.

Каждый архив проверяется сразу после записи, хранятся 14 дней. Итог каждого запуска — одна строка `OK` / `FAIL` / `SKIP` в `/var/backups/logacademy/backup.log`. Бэкапы лежат на том же сервере. Установка и восстановление — `DEPLOYMENT.md`.
